# 🚀 Project Overview

This project performs a complete NLP analysis pipeline on **Google Play Store Reviews** to uncover user opinions, emotional patterns, and hidden discussion topics.

The workflow converts unstructured textual reviews into meaningful business insights through:

* Text Cleaning
* NLP Preprocessing
* Sentiment Analysis
* Word Frequency Analysis
* WordCloud Generation
* Topic Modeling using LDA
* Data Visualization
